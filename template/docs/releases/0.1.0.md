## {{app_title}} 0.1.0

**The first release of {{app_title}}.** It is built on the Krifmaz kit, so it starts with Encore's look and its
ease-of-use features.

### What's in it
- **What's new**: a short note after each update, and the full list under Settings → What's new.
- **Copyable errors**: every error stays until closed and can be copied in full.
- **Bug reports**: describe what went wrong and attach screenshots; the admin answers in the same place.
- **Diagnostics**: one page that checks the data folder and the database and says how to fix what is wrong.
- **Updates**: an open page reloads by itself when the server has a new version.
