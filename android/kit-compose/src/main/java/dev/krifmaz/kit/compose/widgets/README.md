# widgets

The small building blocks of an app's screens, drawn like the web's CSS classes: `KitButton` (`.btn`),
`SmallButton` (`.btn.sm`), `Badge` (`.badge`), `CardBox` (`.card`), `KitField` (`.input`), `ErrorBox`
(`.error-box` with Try again), `EmptyState` (`.empty`), `SectionHead`, `ChoiceRow` (`.tabs`), `RowDivider`,
`PopMenu` / `MoreButton` (the "⋯" menu), `BackBar`, `Spinner`, and the `Gutter`.

Confirm dialogs live in [`dialogs`](../dialogs/README.md).
