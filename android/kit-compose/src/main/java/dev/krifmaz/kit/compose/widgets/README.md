# widgets

The small building blocks of Encore's screens, drawn like the web's CSS classes: `KitButton` (`.btn`),
`SmallButton` (`.btn.sm`), `Badge` (`.badge`), `CardBox` (`.card`), `KitField` (`.input`), `ErrorBox`
(`.error-box` with Try again), `EmptyState` (`.empty`), `SectionHead`, `ChoiceRow` (`.tabs`), `RowDivider`,
`PopMenu` / `MoreButton` (the "⋯" menu), `ConfirmDialog`, `BackBar`, `Spinner`, and the `Gutter`.

From Encore's `ui/components/Common.kt` and the shared widgets of its screens.
