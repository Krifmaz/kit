# demo

The kit demo app (`dev.krifmaz.kit.demo`): every kit-compose component on one scrolling screen in the Encore theme
(`KitTheme(theme = KitTheme.Encore)`), plus Settings → What's new from an in-memory changelog. It turns on the debug
checks (`KitPerf`) and ships a Baseline Profile generated by `:baselineprofile`.

```sh
gradle -p android :demo:assembleDebug          # build
gradle -p android :demo:installDebug           # on a connected device
```

The release build is signed with the debug key: the demo is never published; the benchmarks install it.
