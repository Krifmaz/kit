## Kit 0.2.0

Apps no longer write their own preferences route for the What's new switch.

- **Preferences route.** `kit_server_changelog::prefs_router("/api/auth/prefs")` serves an account's preferences: `GET` answers them, `PUT` merges a JSON object into them (a null removes a key). The template uses it.
- **App headers on every call.** `HttpBackend::with_headers` adds an app's own headers, such as a CSRF token, and errors read a server's `message` or `error` when it sends no `detail`. `api::patch` sends `PATCH`.
