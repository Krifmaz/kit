## Kit 0.8.0

A new server now asks its first visitor to create the owner account, instead of making one with a password in its log.

- **Create your account.** While a server has no owner, the web, desktop and Android apps show "Create your account" (username, password twice, optional email) instead of the sign-in page, and sign in with the new account once it is made.
- **A setup code keeps it yours.** The screen needs a one-time setup code that the server prints in its log when it starts, so nobody else on the network can claim the server first. It stops working the moment the owner exists; a restart before then prints a new one. Wrong codes are limited.
- **Unattended installs still work.** Set the owner's name and password in the app's settings (in the template `APP_ADMIN_USER` and `APP_ADMIN_PASSWORD`) and the owner is made at start, with no setup screen.

New crate: `kit-server-setup`. The app makes the owner with its own rules for names and passwords.
