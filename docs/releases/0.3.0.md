## Kit 0.3.0

App icons in the kit's look.

- **kit-icons.** An app draws one small glyph (24 × 24 SVG, `currentColor` plus an optional `{accent-2}` detail) and `kit-icons` makes its whole icon set on the kit's tile in the Encore colours: SVG favicon, 32/192/512 px PNGs, a maskable icon, the Apple touch icon, a web manifest and the `<head>` tags to paste in.
- **Run it** with `cargo install --git https://github.com/Krifmaz/kit --tag v0.3.0 kit-icons`, then `kit-icons glyph.svg web/public/icons --name "My App"`. `--check` fails when the folder is out of date.
- The rules for a good glyph are in DESIGN.md §5 "App icons".
