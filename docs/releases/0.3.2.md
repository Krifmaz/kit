## Kit 0.3.2

A command palette for web apps: press Ctrl+K (⌘K on a Mac) and type to find any action or page.

- **One box for everything.** The app hands the kit its commands, grouped (Actions, Go to, or its own groups), each with a label, an optional hint and icon, and what it does. A source can load more each time the palette opens, such as the app's records.
- **Finds what you mean.** With nothing typed it lists every command, then the first six of each loaded group. Typing matches labels first, then hints, ignoring case.
- **Keyboard first.** Up and Down move, Enter runs, Escape closes; a click runs a command too. A search button can open it with `palette::open()`.
- **Accessible and themed.** A dialog with a combobox and a listbox of options, drawn by the kit's stylesheet in every theme.
- **For app authors:** `kit_leptos::palette::install(Palette::new(commands).source(|| async { … }))`; the words are `config.words.palette`. The rules (`kit_rules::palette`) are plain Rust, ready for the desktop and Android clients.
