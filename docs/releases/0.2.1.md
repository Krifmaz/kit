## Kit 0.2.1

The "server isn't answering" banner no longer shows while the server is answering.

- **Upstream errors are not a down server.** A 502, 503 or 504 that carries the app's own `x-<app id>` header comes from the app's server, about something behind it, so it is shown as that error. Only a failed request, or an answer without the header (a proxy's page), counts as the server not answering.
- **One failure is not enough.** The banner shows after 2 failed calls in a row, or 5 seconds after a failure with no call answered since. Any answered call ends the count.
- **Cancelled calls are ignored.** An aborted call, or one cut off because the page is being left, raises nothing and fails with "The request was cancelled".
